# Simulation Logs

This folder contains the development log of the Photonics Simulator project.

The purpose of these logs is to record:

- what was implemented,
- why it was implemented,
- which parameters were used,
- what was observed,
- what problems appeared,
- what decisions were made,
- and what should be improved next.

These logs are written as a technical lab notebook. They are not only a personal diary. They are part of the project documentation.

---
